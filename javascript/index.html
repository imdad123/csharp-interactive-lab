Equivalent concepts

JavaScript arrays and objects cover many everyday collection tasks; Map and Set provide dedicated keyed and unique-value collections. TypeScript interfaces and types describe shapes at compile time but are erased at runtime, unlike C# runtime interfaces and reflection metadata. JavaScript Promises and async/await are the normal asynchronous model; Node.js APIs are frequently non-blocking.
