TRACK 03

JavaScript & TypeScript Engineering

One language ecosystem across browser and server: learn JavaScript deeply, then use TypeScript to add static type checking and maintainability to larger applications.

HMS projects: appointment booking interface, patient portal, admin dashboard and Node.js REST API.

Roadmap modules

  1. JavaScript foundations: values, types, operators, control flow, functions and scope.
  2. Arrays, objects, Map, Set, destructuring, spread/rest and modules.
  3. DOM, events, forms, browser APIs, fetch and client-side validation.
  4. Closures, prototypes, classes, this, inheritance and composition.
  5. Promises, async/await, event loop, microtasks, timers and error handling.
  6. TypeScript: annotations, inference, unions, narrowing, generics, interfaces, utility types and strict mode.
  7. Node.js runtime, npm, package scripts, filesystem, streams and environment configuration.
  8. Express and NestJS, REST APIs, middleware, validation, authentication and authorization.
  9. Testing with Vitest/Jest, API tests, linting, formatting and build tooling.
  10. React fundamentals, components, props, state, hooks, routing and data fetching.
  11. Production: security, performance, Docker, CI/CD and cloud deployment.

Equivalent concepts

JavaScript arrays and objects cover many everyday collection tasks; Map and Set provide dedicated keyed and unique-value collections. TypeScript interfaces and types describe shapes at compile time but are erased at runtime, unlike C# runtime interfaces and reflection metadata. JavaScript Promises and async/await are the normal asynchronous model; Node.js APIs are frequently non-blocking.
