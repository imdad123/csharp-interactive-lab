JAVASCRIPT REFERENCE

Production build, security and deployment

Connect application development to reproducible builds, CI/CD and reliable operations.

Build and package

npm ci
npm run lint
npm run typecheck
npm test
npm run build

Commit package-lock.json, use supported Node LTS releases, pin production dependencies and make builds reproducible.

Docker and deployment

Use multi-stage Docker builds, non-root users, health endpoints, environment variables and external secret stores. Do not bake credentials into images. Deploy to a managed container/app service or Kubernetes only when the operational complexity is justified.

Observability and resilience

Use structured logs, request correlation IDs, metrics, distributed traces, timeouts, bounded retries and graceful shutdown. Protect APIs with authentication, authorization, rate limits and input validation.
