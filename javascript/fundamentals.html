JavaScript and TypeScript fundamentals

Core syntax, types, functions, control flow, validation and TypeScript contracts.

Values, types and variables

const patientId = 101;
let patientName = "Amina Khan";
let consultationFee = 1800;
const isActive = true;
const appointmentDate = new Date("2026-12-01T10:30:00");

if (typeof patientId !== "number" || !Number.isInteger(patientId)) {
  throw new TypeError("patientId must be an integer");
}

JavaScript is dynamically typed. TypeScript adds compile-time checking, but types are erased at runtime. Validate data received from HTTP, storage or users even when the project uses TypeScript.

Functions, scope and validation

function calculateBalance(total, paid) {
  if (!Number.isFinite(total) || !Number.isFinite(paid) ||
      total < 0 || paid < 0 || paid > total) {
    throw new RangeError("Invalid billing amounts");
  }
  return total - paid;
}

const formatPatient = (patient) =>
  `${patient.mrn} — ${patient.name}`;

Learn declarations, parameters, return values, default/rest parameters, lexical scope, closures, hoisting and the difference between function declarations and arrow functions.

Control flow and error handling

function appointmentLabel(status) {
  switch (status) {
    case "booked": return "Scheduled";
    case "completed": return "Visited";
    case "cancelled": return "Cancelled";
    default: return "Unknown";
  }
}

try {
  const balance = calculateBalance(2000, 500);
  console.log(balance);
} catch (error) {
  console.error("Could not calculate balance", error);
}

Also learn optional chaining, nullish coalescing, truthiness pitfalls, strict equality, loops, break/continue and early returns.

TypeScript contracts

type AppointmentStatus = "booked" | "completed" | "cancelled";

interface Appointment {
  id: number;
  patientId: number;
  doctorId: number;
  startsAt: string;
  status: AppointmentStatus;
}

function canCancel(appointment: Appointment): boolean {
  return appointment.status === "booked";
}

Use strict mode, union types, narrowing, generics, utility types and runtime schema validation (for example Zod) at external boundaries.
