Node.js service example

import express from "express";

const app = express();
app.use(express.json());

app.get("/api/patients/:id", async (req, res, next) => {
  try {
    const id = Number(req.params.id);
    if (!Number.isInteger(id) || id <= 0) {
      return res.status(400).json({ error: "Invalid patient id" });
    }
    const patient = await patientService.getById(id);
    if (!patient) return res.status(404).json({ error: "Not found" });
    return res.json(patient);
  } catch (error) {
    next(error);
  }
});

app.listen(process.env.PORT ?? 3000);

Use centralized error middleware, request validation, authentication, authorization, rate limiting and structured logging. Never trust a patient ID merely because it appears in the route.

REST and API contracts

  • Use resource-oriented URLs and correct HTTP methods/status codes.
  • Return stable DTOs, not raw database records.
  • Use pagination, filtering, sorting and API versioning deliberately.
  • Implement idempotency keys for retryable payment operations.
  • Document endpoints with OpenAPI and generate typed clients when useful.
