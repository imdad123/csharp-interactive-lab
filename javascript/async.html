Promises, async/await and the event loop

Build responsive I/O workflows and understand scheduling, cancellation and concurrency.

Promises and async/await

async function getPatient(patientId) {
  const response = await fetch(`/api/patients/${patientId}`);
  if (!response.ok) {
    throw new Error(`Request failed: ${response.status}`);
  }
  return response.json();
}

try {
  const patient = await getPatient(101);
  console.log(patient);
} catch (error) {
  console.error("Patient lookup failed", error);
}

Event loop and concurrency model

JavaScript executes synchronous code on an event loop. Promise callbacks use the microtask queue; timers and I/O callbacks have their own scheduling. Async I/O does not make CPU-heavy loops parallel. Use worker threads or separate services for CPU-intensive work.

Cancellation and timeouts

const controller = new AbortController();
const timeout = setTimeout(() => controller.abort(), 5000);

try {
  const response = await fetch("/api/appointments", {
    signal: controller.signal
  });
} finally {
  clearTimeout(timeout);
}
