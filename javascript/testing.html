JAVASCRIPT REFERENCE

Testing and code quality

Unit, integration and end-to-end testing for web applications.

Unit tests with Vitest

import { describe, it, expect } from "vitest";
import { calculateBalance } from "./billing.js";

describe("calculateBalance", () => {
  it("returns unpaid balance", () => {
    expect(calculateBalance(2000, 500)).toBe(1500);
  });

  it("rejects payment greater than invoice", () => {
    expect(() => calculateBalance(1000, 1200)).toThrow();
  });
});

Integration and browser tests

Test API routes with a test database, test authentication/authorization boundaries, and use Playwright for end-to-end workflows such as booking an appointment and collecting payment. Keep tests deterministic and isolate external SMS/email services behind adapters.

Quality and security tools

Use ESLint, Prettier, TypeScript strict mode, dependency audits, secret scanning, SAST and lockfile review. Run these checks in GitHub Actions or another CI platform on every pull request.
