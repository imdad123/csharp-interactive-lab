Objects, arrays and collections

Choose arrays, objects, Map, Set and iteration tools for real application data.

Arrays and object records

const patients = [
  { id: 101, name: "Amina", active: true },
  { id: 102, name: "Bilal", active: false }
];

const active = patients.filter(p => p.active);
const names = active.map(p => p.name);
const found = patients.find(p => p.id === 101);

Map and Set

const patientsById = new Map();
patientsById.set(101, { id: 101, name: "Amina" });
const patient = patientsById.get(101);

const visitedDoctorIds = new Set([4, 7, 4]);
console.log(visitedDoctorIds.size); // 2

Use Map for arbitrary key types and explicit key/value semantics; use Set for uniqueness and membership. Plain objects are often best for JSON-shaped records.

Destructuring, spread and immutability

const { id, name } = patient;
const updated = { ...patient, name: "Amina Khan" };
const nextQueue = [...currentQueue, newAppointment];

Spread is shallow. Nested objects remain shared references unless copied deliberately. Avoid mutating shared state in UI applications when predictable state transitions matter.

Iteration and functional methods

const total = invoices
  .filter(x => x.status === "unpaid")
  .reduce((sum, x) => sum + x.balance, 0);

const grouped = Object.groupBy
  ? Object.groupBy(appointments, x => x.doctorId)
  : appointments.reduce((acc, item) => {
      (acc[item.doctorId] ??= []).push(item);
      return acc;
    }, {});

Learn for...of, forEach, map, filter, find, some, every, reduce, sort and iterator protocols. Use sorting copies where mutation would surprise callers.
