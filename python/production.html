PYTHON REFERENCE

Python packaging, Docker and production

Prepare Python applications for repeatable builds, CI/CD, deployment and operations.

Dependency and build commands

python -m pip install -r requirements.txt
ruff check .
ruff format --check .
mypy app
pytest --cov=app

Pin dependencies, use a lock file, separate development dependencies and keep secrets in environment-specific secret stores.

Docker and service deployment

Use a slim, supported Python base image, install only runtime dependencies, run as a non-root user and expose health/readiness endpoints. Deploy FastAPI behind a production ASGI server and reverse proxy or managed container platform.

Observability and reliability

Use structured logs, metrics, traces, correlation IDs, timeouts, bounded retries and graceful shutdown. Monitor latency, error rate, saturation, queue depth and database pool usage.
