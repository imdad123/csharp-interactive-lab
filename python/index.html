TRACK 04

Python Engineering

Learn Python as a production language for APIs, automation, data processing and AI—not only as a scripting language.

HMS projects: appointment reminder worker, reporting automation, FastAPI patient service and later medical AI integrations.

Roadmap modules

  1. Python runtime, syntax, variables, built-in types, operators and control flow.
  2. Lists, tuples, dictionaries, sets, comprehensions and iteration protocols.
  3. Functions, arguments, scope, modules, packages, virtual environments and pip.
  4. OOP, dataclasses, properties, inheritance, composition and protocols.
  5. Exceptions, context managers, files, pathlib, JSON and logging.
  6. Type hints, generics, protocols, mypy/pyright and modern Python typing.
  7. Iterators, generators, decorators and resource management.
  8. Asyncio, async/await, tasks, concurrency and multiprocessing.
  9. FastAPI and Django, HTTP, REST, validation, authentication and authorization.
  10. SQLAlchemy, DB-API, migrations, transactions and SQL Server/MySQL drivers.
  11. pytest, fixtures, mocks, integration tests, linting and formatting.
  12. Automation, data pipelines, pandas basics and production observability.
  13. Docker, CI/CD, cloud deployment and secure configuration.

Equivalent concepts

Python lists resemble C# List for ordered mutable collections; dict maps to Dictionary; set maps to HashSet. Python protocols and duck typing often provide flexibility where C# uses explicit interfaces. Python async/await uses asyncio for cooperative concurrency, while CPU-bound work often needs processes or native libraries.
