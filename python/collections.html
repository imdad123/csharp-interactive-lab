Python collections and iteration

Use Python's built-in data structures, iteration protocols and lazy generators effectively.

Lists, tuples, dictionaries and sets

patients = [
    {"id": 101, "name": "Amina", "active": True},
    {"id": 102, "name": "Bilal", "active": False},
]

patients_by_id = {p["id"]: p for p in patients}
active_names = [p["name"] for p in patients if p["active"]]
doctor_ids = {4, 7, 4}
print(doctor_ids)  # {4, 7}

List is ordered and mutable; tuple is ordered and immutable; dict maps keys to values; set stores unique hashable values. Choose based on access and mutation patterns.

Iteration protocols and generators

def stream_appointments(cursor):
    for row in cursor:
        yield {
            "id": row.appointment_id,
            "patient_id": row.patient_id,
        }

for item in stream_appointments(database_cursor):
    process(item)

Generators yield values lazily and can reduce memory use for large exports. Understand iter, next, generator expressions and context-managed resources.

Comprehensions and functional operations

unpaid_balances = {
    invoice["id"]: invoice["balance"]
    for invoice in invoices
    if invoice["balance"] > 0
}

total_due = sum(
    invoice["balance"]
    for invoice in invoices
    if invoice["status"] == "unpaid"
)

Use comprehensions for clear transformations; avoid deeply nested comprehensions that obscure business rules.

Sorting and grouping

appointments.sort(key=lambda a: (a["doctor_id"], a["starts_at"]))

from itertools import groupby
for doctor_id, rows in groupby(
    appointments, key=lambda a: a["doctor_id"]
):
    doctor_appointments = list(rows)

itertools provides efficient iteration utilities. Remember groupby groups consecutive equal keys, so sort first when needed.
