Values, variables and core types

patient_id: int = 101
patient_name: str = "Amina Khan"
consultation_fee: int = 1800  # store money as integer minor units
is_active: bool = True

from datetime import date

Python is dynamically typed, but annotations describe intended contracts for editors and static analyzers. They do not automatically validate untrusted runtime data.

Conditions, loops and validation

def calculate_balance(total: int, paid: int) -> int:
    if total < 0 or paid < 0 or paid > total:
        raise ValueError("Invalid billing amounts")
    return total - paid

for appointment in appointments:
    if appointment["status"] == "booked":
        print(appointment["patient_name"])

Functions and parameter behavior

def create_appointment(
    patient_id: int,
    doctor_id: int,
    starts_at: str,
    *,
    reason: str = "Consultation",
) -> dict[str, object]:
    return {
        "patient_id": patient_id,
        "doctor_id": doctor_id,
        "starts_at": starts_at,
        "reason": reason,
    }

Understand positional-only and keyword-only parameters, defaults, *args, **kwargs, scope, closures, decorators and the mutable-default-argument pitfall.
