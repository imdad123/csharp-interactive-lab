Python testing and quality engineering

Use unit, integration and API tests to protect application behavior.

pytest unit tests

import pytest
from billing import calculate_balance

def test_calculates_outstanding_balance():
    assert calculate_balance(2000, 500) == 1500

def test_rejects_payment_above_total():
    with pytest.raises(ValueError):
        calculate_balance(1000, 1200)

Fixtures, mocks and integration tests

Use fixtures for repeatable setup, monkeypatch or mocks for external boundaries, and integration tests with a real test database. Test API authentication, authorization, transactions and failure paths.

Quality tools

Use Ruff for linting/formatting, mypy or Pyright for static typing, coverage reports and dependency/security scans. Run these in CI for every pull request.
