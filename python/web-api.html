FastAPI, databases and REST APIs

Build validated APIs with clear business boundaries, secure database access and documented contracts.

FastAPI endpoint and Pydantic validation

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI()

class AppointmentCreate(BaseModel):
    patient_id: int = Field(gt=0)
    doctor_id: int = Field(gt=0)
    starts_at: str

@app.post("/api/appointments", status_code=201)
async def create_appointment(request: AppointmentCreate):
    appointment = await appointment_service.book(request)
    if appointment is None:
        raise HTTPException(409, "Appointment slot unavailable")
    return appointment

Validate input at the boundary, then enforce business rules in an application service. A Pydantic model validates data shape; it does not replace authorization or transaction-level concurrency controls.

Database access

Use SQLAlchemy 2.x, SQLModel or a direct DB-API driver depending on requirements. Learn sessions, connection pools, parameterized queries, migrations with Alembic, transactions and async driver limitations.

HTTP and API design

  • HTTP methods, status codes, headers, cookies and content negotiation.
  • REST resource design, pagination, filtering and API versioning.
  • OAuth2/OIDC integration, JWT validation and role/permission checks.
  • OpenAPI docs, idempotency, rate limiting and request correlation.
  • Centralized exception handling and safe error responses.
