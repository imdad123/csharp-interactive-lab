# C# Mastery Interactive Lab

A visual-first interactive learning platform for professional C# and .NET development.

## Curriculum
- C# fundamentals and control flow
- .NET runtime, CLR, IL, JIT, assemblies
- Object-oriented programming and SOLID foundations
- Collections, generics, LINQ
- Exceptions, delegates, events, async/await
- Modern C# language features
- Dependency injection and application architecture
- Unit and integration testing
- ASP.NET Core, Minimal APIs, middleware
- EF Core, SQL Server, ADO.NET, transactions
- HospitalApp.Console project-based practice

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Deploy by importing this repository into Vercel and selecting the Next.js framework preset.
