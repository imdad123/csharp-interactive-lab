LEARNING PLAN

Git professional roadmap

A practical learning sequence for individual development, team collaboration and production delivery.

Phase 1 — Version control foundations

Why version control exists, distributed Git model, repository, working tree, staging/index, commits, hashes, status, diff, log, .gitignore and local history.

Phase 2 — Branching and integration

Branches, HEAD, checkout/switch, merge, fast-forward, three-way merge, conflicts, rebase, cherry-pick and safe branch deletion.

Phase 3 — Team collaboration

Remote repositories, origin/upstream, fetch, pull, push, tracking branches, feature branches, pull requests, code review, review feedback and branch protection.

Phase 4 — Recovery and advanced operations

Restore, reset modes, revert, stash, reflog, tags, bisect, blame, submodules, worktrees and repository maintenance. Learn which commands rewrite shared history and which preserve it.

Phase 5 — Professional delivery

Commit conventions, semantic versioning, release branches, changelogs, GitHub Actions, CI checks, secrets, protected main branch, deployment workflows and incident recovery.

Hospital HMS team exercise

  1. Create a repository and protect main.
  2. Developer A builds patient registration on feature/patient-registration.
  3. Developer B fixes appointment conflict validation on bugfix/appointment-conflict.
  4. Open pull requests, review, run tests and merge.
  5. Tag a release and deploy to staging.
  6. Revert a faulty release commit without erasing shared history.
