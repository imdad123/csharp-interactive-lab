PHASE 7 · 22 TOPICS

Phase 7 — Delegates, Events and Functional Programming

Complete topic-by-topic reference with explanations, syntax and practical Hospital Management System examples.

1. What is a delegate?

A delegate is a type-safe reference to one or more methods with a compatible signature. It enables callbacks and passing behavior as data.

public delegate decimal FeeRule(decimal amount);
FeeRule rule = amount => amount * 0.1m;

2. Delegate declaration

A delegate declaration defines the method signature that can be assigned to the delegate.

public delegate void AuditWriter(string action);
AuditWriter writer = Console.WriteLine;

3. Multicast delegates

A multicast delegate holds an invocation list and calls registered methods in order. If a handler throws, later handlers may not execute.

Action notify = SendEmail;
notify += RefreshDashboard;
notify();

4. Delegate chaining

Delegate chaining combines handlers using += and removes handlers using -=. Invocation is synchronous unless the handler itself starts asynchronous work.

Action onSave = WriteAudit;
onSave += QueueReceipt;
onSave -= WriteAudit;

5. Anonymous methods

Anonymous methods use the delegate keyword to define an inline method without a named method declaration. Lambdas are more common in modern C#.

Func<int, int> doubleValue = delegate(int n) { return n * 2; };

6. Lambda expressions

Lambdas express inline functions and are used extensively by LINQ, events, callbacks and async workflows.

var overdue = invoices.Where(i => i.DueDate < today);

7. Func

Func represents a delegate that returns a value. Its final generic type parameter is the return type.

Func<Patient, string> getMrn = p => p.Mrn;

8. Action

Action represents a delegate with no return value. It can accept up to 16 input parameters in its generic forms.

Action<string> audit = message => logger.LogInformation("{Message}", message);

9. Predicate

Predicate represents a method that accepts T and returns bool. It is often used for filtering and search.

Predicate<Patient> hasBalance = p => p.Balance > 0;

10. Events

Events provide a publisher/subscriber mechanism based on delegates. Subscribers can listen, but only the declaring type can raise the event.

public event EventHandler? AppointmentConfirmed;

11. Event publishers and subscribers

The publisher raises an event when something happens; subscribers respond without the publisher knowing their concrete types.

workflow.Confirmed += (_, args) => SendConfirmation(args.AppointmentId);

12. EventHandler

EventHandler and EventHandler are standard .NET event delegate patterns. Custom event args carry event-specific data.

public event EventHandler<AppointmentEventArgs>? Confirmed;

13. Custom event arguments

Custom EventArgs types provide strongly typed context to subscribers.

public sealed class AppointmentEventArgs(int id) : EventArgs { public int AppointmentId { get; } = id; }

14. Event subscription and unsubscription

Subscribe with += and unsubscribe with -=. Unsubscribe when a long-lived publisher outlives the subscriber.

publisher.Changed += OnChanged;
publisher.Changed -= OnChanged;

15. Event memory leaks

A publisher retains references to subscribed delegates, which can keep subscribers alive. Use explicit unsubscription, weak-event patterns or short-lived publishers.

publisher.Completed += HandleCompleted;
// On disposal/lifecycle end:
publisher.Completed -= HandleCompleted;

16. Custom event accessors

Custom add/remove accessors allow control over how event handlers are stored or registered. Use only when standard field-like events are insufficient.

private EventHandler? _changed;
public event EventHandler Changed { add => _changed += value; remove => _changed -= value; }

17. Closures

A closure captures variables from the surrounding scope. Captured variables live as long as the delegate that references them.

int threshold = 10;
Func<int, bool> isLarge = value => value > threshold;

18. Higher-order functions

A higher-order function accepts a function as input or returns a function. It enables reusable policies and composable behavior.

static Func<decimal, decimal> ApplyRate(decimal rate)
    => amount => amount * rate;
var tax = ApplyRate(0.15m);

19. Functional programming concepts

Functional style favors pure transformations, immutable data and composition. C# supports this style alongside object-oriented programming.

var totals = invoices.Where(i => i.IsFinalized).Select(i => i.Total).ToArray();

20. Immutability

Immutable data cannot be changed after creation. It reduces accidental shared-state mutation and simplifies reasoning across threads.

public sealed record PatientSnapshot(int Id, string Name);

21. Pure functions

A pure function returns the same output for the same inputs and has no observable side effects. It is easy to test and reuse.

static decimal CalculateTax(decimal amount, decimal rate) => amount * rate;

22. Side effects

Side effects include database writes, file access, logging, network calls and mutation of shared state. Isolate them at application boundaries.

await repository.SaveAsync(patient, ct); // side effect belongs in an infrastructure boundary
