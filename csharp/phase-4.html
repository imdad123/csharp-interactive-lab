Phase 4 — Collections and Data Structures

Complete topic-by-topic reference with explanations, syntax and practical Hospital Management System examples.

1. Arrays

Arrays have a fixed length and store elements of one type with zero-based indexing.

int[] wardBeds = [10, 12, 8];
Console.WriteLine(wardBeds[0]);

2. Multidimensional arrays

Rectangular arrays represent rows and columns with a fixed dimension shape.

int[,] occupancy = { { 8, 10 }, { 4, 6 } };
Console.WriteLine(occupancy[0, 1]);

3. Jagged arrays

Jagged arrays are arrays whose elements are arrays; each inner array can have a different length.

int[][] shifts = [[1, 2], [1, 2, 3], [2]];
Console.WriteLine(shifts[1][2]);

4. Array manipulation

Array APIs provide sorting, searching, copying and resizing operations. Resizing creates a new array; prefer List when size changes frequently.

int[] ids = [3, 1, 2];
Array.Sort(ids);
int index = Array.BinarySearch(ids, 2);

5. List

List is a resizable ordered collection with fast indexed access and amortized append.

var patients = new List<string> { "Amina", "Bilal" };
patients.Add("Sara");
patients.Remove("Bilal");

6. Dictionary

Dictionary maps unique keys to values and provides expected O(1) lookup.

var patientsById = new Dictionary<int, string> { [1] = "Amina" };
if (patientsById.TryGetValue(1, out var name)) Console.WriteLine(name);

7. HashSet

HashSet stores unique elements and supports efficient membership checks and set operations.

var mrns = new HashSet<string>(StringComparer.OrdinalIgnoreCase);
mrns.Add("MR-1");
bool duplicate = !mrns.Add("mr-1");

8. SortedSet

SortedSet stores unique values in sorted order and supports range/set operations with logarithmic updates.

var queueNumbers = new SortedSet<int> { 4, 2, 3, 2 };
Console.WriteLine(queueNumbers.Min);

9. SortedDictionary

SortedDictionary stores key/value pairs ordered by key, with logarithmic lookup and updates.

var slots = new SortedDictionary<DateTime, string>();
slots[new DateTime(2026, 1, 1, 9, 0, 0)] = "Dr. Ali";

10. Queue

Queue is FIFO: first in, first out. It models reception queues and work scheduling.

var reception = new Queue<int>();
reception.Enqueue(101);
int nextPatient = reception.Dequeue();

11. Stack

Stack is LIFO: last in, first out. It is useful for undo history and depth-first traversal.

var undo = new Stack<string>();
undo.Push("Created invoice");
string lastAction = undo.Pop();

12. LinkedList

LinkedList supports efficient insertion/removal when a node reference is already known, but has no constant-time indexed access.

var list = new LinkedList<string>();
var node = list.AddLast("Amina");
list.AddAfter(node, "Bilal");

13. Collection initialization

Collection initializers call Add methods to populate collections at creation time.

var departments = new List<string> { "ER", "Cardiology", "Pediatrics" };

14. Collection expressions

C# 12 collection expressions use [] and can target arrays, spans and supported collection types when a target type is known.

string[] wards = ["ICU", "ER"];
List<int> beds = [1, 2, 3];

15. IEnumerable

IEnumerable represents a sequence that can be iterated. It does not promise indexing, mutation or a specific storage mechanism.

IEnumerable<string> names = patients.Select(p => p.Name);
foreach (var name in names) Console.WriteLine(name);

16. ICollection

ICollection adds Count and mutation operations such as Add and Remove to enumeration.

ICollection<string> specialties = new List<string>();
specialties.Add("Cardiology");

17. IList

IList adds indexed access and insertion/removal by index. Use it when callers genuinely need list semantics.

IList<string> names = new List<string> { "Amina", "Bilal" };
names[0] = "Sara";

18. IReadOnlyCollection

IReadOnlyCollection exposes enumeration and Count without exposing collection mutation through the interface.

IReadOnlyCollection<PatientDto> activePatients = service.GetActivePatients();
Console.WriteLine(activePatients.Count);

19. IReadOnlyList

IReadOnlyList adds read-only indexed access to a collection view. It does not guarantee the underlying data cannot change elsewhere.

IReadOnlyList<string> wards = ["ER", "ICU"];
Console.WriteLine(wards[1]);

20. IEnumerator

IEnumerator controls iteration using MoveNext and Current. foreach manages the enumerator and disposal automatically.

using var iterator = wards.GetEnumerator();
while (iterator.MoveNext()) Console.WriteLine(iterator.Current);

21. Custom collections

A custom collection can enforce domain-specific rules while exposing standard collection interfaces. Prefer wrapping a collection rather than inheriting from List when enforcing invariants.

public sealed class UniqueMrnCollection
{
    private readonly HashSet<string> _items = new(StringComparer.OrdinalIgnoreCase);
    public bool Add(string mrn) => _items.Add(mrn.Trim());
}

22. Immutable collections

Immutable collections produce new collection instances when changed, making shared state safer to reason about.

using System.Collections.Immutable;
var codes = ImmutableArray.Create("ER", "ICU");
var updated = codes.Add("OPD");

23. Concurrent collections

Concurrent collections provide thread-safe operations for shared concurrent access. They do not make multi-step business transactions automatically atomic.

var jobs = new System.Collections.Concurrent.ConcurrentQueue<int>();
jobs.Enqueue(1001);
if (jobs.TryDequeue(out int jobId)) Console.WriteLine(jobId);

24. Choosing the right collection

Choose by access pattern: List for ordered indexed data, Dictionary for key lookup, HashSet for uniqueness, Queue for FIFO and Stack for LIFO. Consider ordering, concurrency and mutation.

// Lookup by patient ID:
Dictionary<int, PatientDto> byId = [];
// Prevent duplicate MRNs:
HashSet<string> uniqueMrns = [];

25. Big-O complexity basics

Big-O describes how operation cost grows with input size. Array/list indexing is O(1), linear search is O(n), and hash lookup is expected O(1); tree-based ordered collections are commonly O(log n).

// Linear search: O(n)
var found = patients.FirstOrDefault(p => p.Id == targetId);
// Dictionary lookup: expected O(1)
var indexed = patientsById.TryGetValue(targetId, out var patient);
