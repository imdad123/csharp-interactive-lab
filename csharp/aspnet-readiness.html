BRIDGE BETWEEN C# AND ASP.NET CORE

C# topics you must know before and during ASP.NET Core

Your eight C# phases cover the core language. These additional topics strengthen the exact skills used repeatedly in web APIs, dependency injection, EF Core and production services.

Important: these are not a replacement for your eight C# phases. Learn the essentials before or alongside the ASP.NET Core guides; study advanced memory/performance APIs later when you have a measured need.

SUPPLEMENT 01

Nullable reference types

Why this matters

Web APIs receive missing, malformed or optional data. Nullable reference types help express whether a reference may be absent and reduce null-related defects.

Code example

#nullable enable
public sealed record PatientDto(Guid Id, string FullName, string? Email);

public PatientDto? FindPatient(Guid id) => null;
var patient = FindPatient(id);
if (patient is not null) Console.WriteLine(patient.FullName);

Practice

Enable nullable reference types in every project. Fix warnings meaningfully; do not silence them all with `!`.

SUPPLEMENT 02

CancellationToken and cooperative cancellation

Why this matters

HTTP clients may disconnect, server requests may time out and background work may be stopped. Cancellation must flow through the full call chain.

Code example

public async Task<Patient?> GetAsync(Guid id, CancellationToken ct)
{
    return await db.Patients
        .AsNoTracking()
        .SingleOrDefaultAsync(x => x.Id == id, ct);
}

Practice

Pass the request cancellation token into EF Core, HttpClient and long-running operations. Do not swallow OperationCanceledException indiscriminately.

SUPPLEMENT 03

IDisposable and IAsyncDisposable

Why this matters

Database connections, streams and other resources must be released deterministically. Async disposal matters when cleanup itself performs asynchronous I/O.

Code example

await using var stream = new FileStream(
    path, FileMode.Open, FileAccess.Read, FileShare.Read,
    bufferSize: 81920, useAsync: true);

await stream.CopyToAsync(destination, ct);

Practice

Learn `using`, `await using`, ownership and lifetime. Never dispose a service injected and owned by the DI container.

SUPPLEMENT 04

Extension methods

Why this matters

Extension methods add discoverable APIs to existing types and are used throughout LINQ and ASP.NET Core registration conventions.

Code example

public static class PatientMappingExtensions
{
    public static PatientResponse ToResponse(this Patient patient) =>
        new(patient.Id, patient.FullName);
}

Practice

Write mapping and registration extension methods. Keep business rules in domain/application services rather than hiding them in generic helpers.

SUPPLEMENT 05

Expression trees

Why this matters

An expression tree represents code as data. LINQ providers such as EF Core inspect expression trees and translate supported operations into SQL.

Code example

Expression<Func<Appointment, bool>> upcoming =
    a => a.StartsAtUtc >= DateTimeOffset.UtcNow;

var rows = await db.Appointments.Where(upcoming).ToListAsync(ct);

Practice

Compare `IEnumerable` delegates with `IQueryable` expression trees. Inspect the SQL generated by EF Core.

SUPPLEMENT 06

System.Text.Json

Why this matters

ASP.NET Core uses JSON serialization for request and response bodies. Serialization options affect public contracts and compatibility.

Code example

var json = JsonSerializer.Serialize(
    new PatientResponse(Guid.NewGuid(), "Amina"),
    new JsonSerializerOptions(JsonSerializerDefaults.Web));

var dto = JsonSerializer.Deserialize<PatientResponse>(json);

Practice

Learn naming policies, converters, enum handling, DateOnly, DateTimeOffset, nulls and safe polymorphism.

SUPPLEMENT 07

Dependency injection and object composition

Why this matters

ASP.NET Core creates controllers, endpoint dependencies and services through DI. Understanding constructor injection and lifetimes is essential.

Code example

builder.Services.AddScoped<IPatientService, PatientService>();
builder.Services.AddScoped<IPatientRepository, PatientRepository>();

public sealed class PatientService(IPatientRepository repository)
    : IPatientService { }

Practice

Understand registrations, constructor injection and scoped/transient/singleton lifetimes before studying ASP.NET Core service architecture.

SUPPLEMENT 08

Span and Memory (advanced)

Why this matters

These APIs support efficient work with contiguous memory and can reduce allocations in performance-sensitive code. Most ordinary web application code does not need them.

Code example

ReadOnlySpan<char> input = "MRN-2026-001";
var prefix = input[..3];
Console.WriteLine(prefix);

Practice

Study slicing, stack-only restrictions, lifetime rules and benchmarking. Use only when profiling identifies allocation or parsing bottlenecks.
