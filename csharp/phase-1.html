Phase 1 — C# Fundamentals

A reference guide in the exact roadmap order. Each topic explains the purpose, shows C# syntax, and connects the idea to a realistic Hospital Management System scenario.

1. Introduction to C# and .NET

C# is a statically typed, general-purpose language. .NET supplies the runtime, base libraries, SDK and application frameworks. C# is the language; .NET is the platform that executes and supports applications.

// Program.cs
Console.WriteLine("Hospital HMS starting...");

2. C# compilation and execution process

The C# compiler converts source code into Intermediate Language (IL) and metadata in an assembly. The .NET runtime loads it, verifies required metadata, and JIT-compiles methods to native machine code when executed.

// Build and run
// dotnet build
// dotnet run
Console.WriteLine(typeof(string).Assembly.FullName);

3. .NET SDK, Runtime and CLR

The SDK contains the CLI, compiler and build tools. The runtime executes applications. The CLR manages execution services such as JIT compilation, garbage collection, exceptions and type safety.

// Inspect installed components in a terminal:
// dotnet --list-sdks
// dotnet --list-runtimes
Console.WriteLine(Environment.Version);

4. Project structure and .csproj

A solution groups projects; a project file declares target framework, compiler settings and dependencies. Source files compile into an assembly. Keep application concerns separated as the solution grows.

// HospitalApp.Console.csproj
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net10.0</TargetFramework>
    <Nullable>enable</Nullable>
    <ImplicitUsings>enable</ImplicitUsings>
  </PropertyGroup>
</Project>

5. Variables and constants

A variable names a storage location whose value can change. Use const for compile-time constants and readonly for values assigned at declaration or in a constructor.

int patientId = 1205;
const int MaxAppointmentsPerDay = 40;
Console.WriteLine(patientId);

6. Data types

Types define the values a variable can hold and the operations available. Common types include int, decimal, double, bool, char, string, DateOnly and DateTimeOffset.

int age = 32;
decimal invoiceTotal = 12500.75m;
bool isAdmitted = true;
DateOnly dateOfBirth = new(1994, 5, 12);
string patientName = "Amina";

7. Value types vs Reference types

Value types copy their value on assignment; reference types copy a reference to an object. This changes how mutation and equality behave. Do not reduce the rule to stack versus heap placement.

int firstAge = 30;
int copiedAge = firstAge;
copiedAge++;
Console.WriteLine(firstAge); // 30
var first = new Patient("Amina");
var second = first;
second.Name = "Sara";
Console.WriteLine(first.Name); // Sara

public class Patient(string name) { public string Name { get; set; } = name; }

8. Implicit and explicit type conversion

Implicit conversions are considered safe by the language. Explicit conversions require a cast or conversion API because information may be lost or the conversion may fail.

int count = 12;
double approximate = count; // implicit
 double measurement = 12.75;
int whole = (int)measurement; // explicit; truncates

9. Type casting

Casting tells the compiler to treat a value as another compatible type. Use safe parsing for text input and pattern matching for runtime object types.

object value = "MR-1205";
if (value is string mrn)
    Console.WriteLine(mrn);

string rawAge = "42";
if (int.TryParse(rawAge, out int age))
    Console.WriteLine(age);

10. var, dynamic and object

var uses compile-time type inference; it remains statically typed. object is the common base type and requires casting/pattern matching to access a specific type. dynamic defers member binding until runtime.

var patientCount = 15; // int
object code = "MR-01";
if (code is string mrn) Console.WriteLine(mrn);
dynamic imported = "legacy-system";
Console.WriteLine(imported.ToUpperInvariant());

11. Operators

Operators perform arithmetic, comparison, logical, null and bitwise operations. Use decimal for financial calculations and parentheses to make business rules unambiguous.

decimal subtotal = 1000m;
decimal tax = subtotal * 0.15m;
decimal total = subtotal + tax;
bool canBook = total > 0 && !string.IsNullOrWhiteSpace("Dr. Ali");

12. Conditional statements

if/else expresses branching when a business decision depends on a condition. Keep conditions readable and extract complicated business rules into named methods.

if (patientAge < 18)
    Console.WriteLine("Guardian details required");
else if (patientAge >= 65)
    Console.WriteLine("Senior patient workflow");
else
    Console.WriteLine("Standard registration");

13. Switch statements and switch expressions

A switch statement is useful for multiple imperative branches. A switch expression returns a value and is concise for mapping a known input to an output.

string category = patientAge switch
{
    < 0 => "Invalid",
    < 18 => "Child",
    < 65 => "Adult",
    _ => "Senior"
};

14. Loops (for, while, do-while, foreach)

Use for when an index matters, foreach to process each item, while when repetition depends on a condition, and do-while when the body must run at least once.

for (int i = 0; i < 3; i++) Console.WriteLine(i);
foreach (string ward in wards) Console.WriteLine(ward);
while (queueCount > 0) queueCount--;
do { attempts++; } while (attempts < 1);

15. Break and Continue

break exits the nearest loop or switch. continue skips the rest of the current iteration and proceeds with the next one.

foreach (var appointment in appointments)
{
    if (appointment.IsCancelled) continue;
    if (appointment.StartsAt > closingTime) break;
    Console.WriteLine(appointment.PatientName);
}

16. Methods and parameters

Methods package behavior behind a named contract. Parameters pass input; return values communicate results. Keep methods focused and name them with verbs.

static decimal CalculateBalance(decimal billed, decimal paid)
{
    return billed - paid;
}
var balance = CalculateBalance(5000m, 2000m);

17. Optional and named parameters

Optional parameters provide defaults; named arguments improve call-site clarity when a method has several parameters. Optional parameters should generally appear after required parameters.

static void SearchPatients(string department, int page = 1, int pageSize = 20) { }
SearchPatients("Cardiology", pageSize: 50, page: 2);

18. Method overloading

Overloads share a method name but differ in parameter count or types. The compiler chooses the best matching signature; return type alone cannot create an overload.

static decimal CalculateFee(decimal amount) => amount;
static decimal CalculateFee(decimal amount, decimal discount) => amount - discount;
var finalFee = CalculateFee(1000m, 100m);

19. Ref, Out and In parameters

ref passes an existing variable by reference; out requires the method to assign a value; in passes by readonly reference. Prefer return values unless by-reference semantics are genuinely useful.

static bool TryGetPatient(int id, out string? name)
{
    name = id == 1 ? "Amina" : null;
    return name is not null;
}
if (TryGetPatient(1, out var name)) Console.WriteLine(name);

20. Local functions

A local function is declared inside another method. It can keep a small helper close to the workflow that uses it and can access the containing method's local variables.

static decimal CalculateInvoice(decimal subtotal)
{
    decimal AddTax(decimal value) => value * 1.15m;
    return AddTax(subtotal);
}

21. Expression-bodied members

Expression-bodied members use => for a single expression. They reduce ceremony but should not obscure validation or multi-step behavior.

public sealed class Invoice(decimal subtotal, decimal tax)
{
    public decimal Subtotal { get; } = subtotal;
    public decimal Total => Subtotal + tax;
}

22. String manipulation

Strings are immutable. Common operations include Trim, Replace, Split, Contains, StartsWith and string comparison options. Normalize identifiers consistently.

string mrn = "  mr-1205 ".Trim().ToUpperInvariant();
string[] parts = "Cardiology,Emergency".Split(',');
bool validPrefix = mrn.StartsWith("MR-", StringComparison.Ordinal);

23. String interpolation

Interpolation inserts expressions into a string using $"...". Use format specifiers for dates, numbers and currency.

string patient = "Amina";
decimal balance = 1250.5m;
string message = $"Patient {patient} has balance {balance:N2}";

24. StringBuilder

StringBuilder is useful when repeatedly appending text in loops. For a few concatenations, normal interpolation is usually simpler.

var report = new System.Text.StringBuilder();
foreach (var row in invoiceLines)
    report.AppendLine($"{row.Description}: {row.Amount:N2}");
string text = report.ToString();

25. Nullable value types

A nullable value type represents either a value or null. It is written T? for value types such as int? or DateOnly?.

int? assignedDoctorId = null;
if (assignedDoctorId.HasValue)
    Console.WriteLine(assignedDoctorId.Value);
DateOnly? dischargeDate = null;

26. Null handling and null-coalescing operators

Use ?. for conditional access, ?? for fallback values and ??= to assign only when null. Null checks should reflect the real domain contract.

string? phone = patient.Phone;
string displayPhone = phone ?? "Not provided";
int length = phone?.Length ?? 0;
patient.Phone ??= "Pending";

27. Scope and lifetime of variables

A variable's scope determines where it can be accessed. Lifetime describes how long its storage/value remains relevant. Local variables, fields, static fields and captured variables have different lifetimes.

static int registrationsToday;
void Register()
{
    int localCount = 1; // local scope
    registrationsToday++; // static field shared by type
}
