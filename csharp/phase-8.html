Phase 8 — Asynchronous and Parallel Programming

Complete topic-by-topic reference with explanations, syntax and practical Hospital Management System examples.

1. Synchronous vs Asynchronous programming

Synchronous work blocks the current flow until complete. Asynchronous I/O allows a thread to serve other work while waiting for database, file or network operations.

// Asynchronous I/O does not require dedicating a thread while waiting.
var patient = await db.Patients.FindAsync([patientId], ct);

2. Thread fundamentals

A thread is an operating-system execution path. Threads execute code; shared mutable state requires synchronization to avoid races.

var thread = new Thread(() => Console.WriteLine("Background thread"));
thread.Start();
thread.Join();

3. Thread lifecycle

A thread is created, started, runs, and eventually terminates. Avoid creating dedicated threads for routine request work; use the ThreadPool/Task abstractions.

var thread = new Thread(ImportPatients);
thread.Start();
thread.Join();

4. ThreadPool

The ThreadPool reuses worker threads for short-running work and supports Task scheduling. Blocking ThreadPool threads can cause starvation.

ThreadPool.QueueUserWorkItem(_ => ProcessBatch());

5. Task

Task represents an asynchronous operation or unit of work; it is not itself a dedicated thread. Await tasks to observe completion and exceptions.

Task saveTask = repository.SaveAsync(patient, ct);
await saveTask;

6. Task vs Thread

Thread is a low-level execution resource; Task is a higher-level representation of work/completion. Prefer Task-based APIs for most application code.

Task.Run(() => RebuildIndex());
// Direct Thread creation is reserved for specialized low-level scenarios.

7. Task.Run

Task.Run queues CPU-bound work to the ThreadPool. Do not wrap naturally asynchronous I/O in Task.Run in server applications.

var hash = await Task.Run(() => ComputeLargeHash(fileBytes), ct);

8. Async and Await

async/await provides readable asynchronous control flow. It does not automatically create a new thread; await yields while an incomplete operation is pending.

public async Task<Patient?> FindAsync(int id, CancellationToken ct)
    => await db.Patients.FindAsync([id], ct);

9. Task vs Task

Task represents completion without a result; Task represents completion that produces a value. Await Task yields T.

Task auditTask = WriteAuditAsync(ct);
Task<int> countTask = CountPatientsAsync(ct);
await auditTask;
int count = await countTask;
