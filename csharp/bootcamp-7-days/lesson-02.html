User Input, Type Conversion & Operators

Make the hospital console application interactive: collect patient information, validate it and calculate a bill.

ConsoleInput validationOperators

1. Why user input?

A hospital receptionist registers many different patients. We cannot hardcode a new patient into the source code for every registration. The program must ask for information while it runs.

Console.ReadLine() reads a line of text entered by the user.

Console.Write("Enter patient name: ");
string patientName = Console.ReadLine()!;

Console.WriteLine($"Patient Name: {patientName}");

Write stays on the same line; WriteLine moves to a new line. ReadLine reads input as text.

Important: Console.ReadLine() returns a nullable string in modern .NET annotations. The ! null-forgiving operator suppresses a compiler warning; it does not validate the input or guarantee a non-null value at runtime.

2. Convert input into the correct type

Even if a user types 35, ReadLine() returns the characters as a string. To do arithmetic, convert the value to a numeric type.

Convert.ToInt32()

Console.Write("Enter patient age: ");
string ageInput = Console.ReadLine()!;
int patientAge = Convert.ToInt32(ageInput);

int.Parse()

int patientAge = int.Parse(Console.ReadLine()!);

Both approaches can throw an exception if the text is not a valid integer. Parsing is appropriate when invalid input is exceptional or has already been validated.

int.TryParse() — safer for user input

Console.Write("Enter patient age: ");
string ageInput = Console.ReadLine()!;

if (int.TryParse(ageInput, out int patientAge))
{
    Console.WriteLine($"Patient Age: {patientAge}");
}
else
{
    Console.WriteLine("Invalid age. Please enter a whole number.");
}

TryParse returns true when conversion succeeds and places the converted value in the out variable. It returns false instead of throwing a format exception for invalid text.

Professional rule: Validate external input at the boundary of your application. For an age, parsing is not enough: also check a sensible business range, such as 0–120.

3. Convert money safely

Use decimal for monetary values such as consultation fees, laboratory charges and medicine charges.

Console.Write("Consultation fee: ");
bool validFee = decimal.TryParse(
    Console.ReadLine(),
    out decimal consultationFee
);

if (validFee && consultationFee >= 0)
{
    Console.WriteLine($"Fee: {consultationFee:C}");
}
else
{
    Console.WriteLine("Enter a valid non-negative fee.");
}

The :C format specifier formats a value as currency using the current culture settings of the application. Configure culture explicitly if the application must always display a particular currency.

4. C# operators

Operators perform calculations, compare values and combine conditions.

Arithmetic operators

OperatorMeaningHospital example
+AdditionConsultation + lab fee
-SubtractionRemaining balance
*MultiplicationMedicine price × quantity
/DivisionSplit a bill
%RemainderCheck even/odd room number
decimal consultation = 1250m;
decimal laboratory = 850m;
decimal medicine = 400m;

decimal totalBill = consultation + laboratory + medicine;
decimal amountPaid = 2000m;
decimal balance = totalBill - amountPaid;

Console.WriteLine($"Total: {totalBill}");
Console.WriteLine($"Balance: {balance}");

Comparison operators

==, !=, >, <, >=, <= compare values and produce a Boolean result.

int patientAge = 17;
bool isAdult = patientAge >= 18;

Console.WriteLine(isAdult); // False

Logical operators

&& means AND, || means OR, and ! means NOT.

bool hasAppointment = true;
bool doctorAvailable = true;

bool canCheckIn = hasAppointment && doctorAvailable;

Console.WriteLine(canCheckIn);

Assignment and increment

int queueNumber = 10;
queueNumber += 1; // same as queueNumber = queueNumber + 1
queueNumber++;    // increment by one

5. Complete practical: patient registration and bill

This example combines keyboard input, conversion, validation and arithmetic. Type it yourself, run it and test invalid values.

Console.WriteLine("=== HOSPITAL REGISTRATION ===");

Console.Write("Patient name: ");
string patientName = Console.ReadLine() ?? "";

Console.Write("Patient age: ");
if (!int.TryParse(Console.ReadLine(), out int age) || age < 0 || age > 120)
{
    Console.WriteLine("Invalid age.");
    return;
}

Console.Write("Consultation fee: ");
if (!decimal.TryParse(Console.ReadLine(), out decimal consultation) || consultation < 0)
{
    Console.WriteLine("Invalid consultation fee.");
    return;
}

Console.Write("Laboratory charges: ");
if (!decimal.TryParse(Console.ReadLine(), out decimal lab) || lab < 0)
{
    Console.WriteLine("Invalid laboratory charges.");
    return;
}

decimal total = consultation + lab;

Console.WriteLine("\n=== PATIENT SUMMARY ===");
Console.WriteLine($"Patient: {patientName}");
Console.WriteLine($"Age: {age}");
Console.WriteLine($"Total bill: {total:C}");

Note: this is a learning example. A production hospital application also needs required-field validation, patient identity rules, persistence, audit logging and authorization.
