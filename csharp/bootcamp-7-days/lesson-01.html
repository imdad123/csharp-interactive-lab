Start from zero. Understand what a C# program is, how it runs, and how to store hospital data in variables.

1. Why do we need C#?

A hospital handles information and decisions: registering patients, assigning doctors, calculating bills and checking appointments. A computer needs precise instructions to perform these operations. A programming language lets us express those instructions.

C# is a general-purpose, strongly typed programming language from Microsoft. It runs on the .NET platform. We will use C# to build the logic of our Hospital Management System before learning how ASP.NET Core exposes that logic through web APIs.

Professional mental model: C# is the language; .NET is the runtime and platform that executes your application and provides libraries for common work.

2. Create and run your first application

Install the current .NET SDK and use Visual Studio or the terminal. Create a console application:

dotnet new console -n HospitalApp.Console
cd HospitalApp.Console
dotnet run

Open Program.cs. A modern console project may start with top-level statements:

Console.WriteLine("Hospital Management System");
Console.WriteLine("Welcome to the patient registration desk.");

Console.WriteLine prints text and moves to a new line. Console.Write prints without automatically moving to a new line.

What happens when you run it?

  1. You write C# source code in .cs files.
  2. The .NET SDK builds the project.
  3. The runtime executes the compiled application.
  4. Your instructions produce output or perform work.

3. Variables: named storage for information

A variable is a named location in which your program stores a value. Think of a patient registration form: it has separate fields for patient name, age, patient number and whether the patient is admitted.

string patientName = "Ayesha Khan";
int patientAge = 34;
decimal consultationFee = 1500.00m;
bool isAdmitted = false;

Console.WriteLine(patientName);
Console.WriteLine(patientAge);
Console.WriteLine(consultationFee);
Console.WriteLine(isAdmitted);

The type tells C# what kind of value a variable can hold. The variable name should describe its purpose.

TypeUseHospital example
stringTextPatient or doctor name
intWhole numbersAge, room number, quantity
longLarge whole numbersLarge identifier values
decimalPrecise decimal arithmeticBill amount, medicine price
doubleFloating-point measurementsScientific calculations
booltrue or falseIs patient admitted?
charOne characterBlood group component or grade
Important: Use decimal for financial values such as invoices and payments. A decimal literal uses the m suffix, for example 1500.00m.

Changing a variable

decimal billAmount = 1500m;
billAmount = 1800m; // updated after adding a service

Console.WriteLine(billAmount);

Use var when the compiler can clearly infer the type from the assigned value:

var doctorName = "Dr. Hamza"; // inferred as string
var wardNumber = 12;          // inferred as int

var does not make a variable dynamically typed. Its type is still determined at compile time.

4. Naming and professional conventions

  • Use camelCase for local variables and parameters: patientName.
  • Use meaningful names; avoid x, a1 or data when a precise name is possible.
  • C# is case-sensitive: patientName and PatientName are different identifiers.
  • End most statements with a semicolon.
  • Use braces to group code blocks as you progress.
