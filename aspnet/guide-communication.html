ASP.NET Core API integrations and real-time

Concept, purpose, code examples and production considerations with hospital application scenarios.

Typed HTTP clients and IHttpClientFactory

Use IHttpClientFactory or typed clients to manage handler lifetimes, centralized configuration and resilience. Apply timeouts and cancellation; retry only operations safe to retry.

builder.Services.AddHttpClient<LaboratoryClient>(client =>
{
 client.BaseAddress = new Uri(builder.Configuration["LabApi:BaseUrl"]!);
 client.Timeout = TimeSpan.FromSeconds(10);
});
public sealed class LaboratoryClient(HttpClient http)
{
 public Task<LabResult?> GetAsync(string id, CancellationToken ct)
  => http.GetFromJsonAsync<LabResult>($"api/results/{Uri.EscapeDataString(id)}", ct);
}

GraphQL and GraphQL.NET / Hot Chocolate

GraphQL exposes a typed schema where clients select fields. Hot Chocolate is a common .NET GraphQL server; GraphQL.NET is another implementation. Apply authorization and query depth/complexity limits.

builder.Services.AddGraphQLServer().AddQueryType<PatientQueries>();
app.MapGraphQL("/graphql");
,

OData

OData exposes standardized filtering, sorting and selection. Limit query options and page sizes so clients cannot generate unbounded expensive database work.

[EnableQuery(PageSize = 50)]
public IQueryable<PatientDto> Get()
 => db.Patients.Select(p => new PatientDto(p.Id, p.Mrn, p.FullName));
,

gRPC and Protocol Buffers

gRPC uses Protocol Buffers contracts over HTTP/2 for strongly typed service-to-service communication and streaming. Evolve contracts compatibly and never reuse removed field numbers.

syntax = "proto3";
service PatientDirectory { rpc GetPatient (PatientRequest) returns (PatientReply); }
message PatientRequest { int32 id = 1; }
message PatientReply { int32 id = 1; string name = 2; }
,

REST API versioning and OpenAPI

OpenAPI describes the API contract for clients, generated SDKs and testing. Version endpoints intentionally and keep documentation aligned with runtime behavior.

builder.Services.AddOpenApi();
var app = builder.Build();
app.MapOpenApi();
// Publish the generated OpenAPI document with your API release.

Manual mapping, AutoMapper and Mapperly

Mapping translates domain/persistence objects into public DTOs. Manual mapping is explicit; AutoMapper uses runtime conventions; Mapperly generates code at compile time. Keep business rules out of mapping.

public sealed record PatientResponse(int Id, string Name);
static PatientResponse Map(Patient entity)
 => new(entity.Id, entity.FullName);
,

WebSockets

WebSockets provide persistent bidirectional communication. They are lower-level than SignalR and require explicit connection lifecycle, framing, cancellation and message-size handling.

app.UseWebSockets();
app.Map("/ws", async context =>
{
 if (!context.WebSockets.IsWebSocketRequest) { context.Response.StatusCode = 400; return; }
 using var socket = await context.WebSockets.AcceptWebSocketAsync();
 // Receive frames with cancellation and size limits.
});
,

SignalR Core

SignalR provides hubs and client libraries for real-time server/client communication. It can use WebSockets and fallback transports; multi-instance deployments need scale-out support.

builder.Services.AddSignalR();
app.MapHub<AppointmentHub>("/hubs/appointments");
public sealed class AppointmentHub : Hub
{
 public Task JoinWard(string ward) => Groups.AddToGroupAsync(Context.ConnectionId, ward);
}
,

API security and authorization

Protect each operation at the resource level, validate tenant/patient ownership, apply rate limits and avoid trusting client-supplied identifiers without authorization checks.

[Authorize(Policy = "Patient.Read")]
[HttpGet("{id:int}")]
public Task<ActionResult<PatientDto>> Get(int id, CancellationToken ct) => ...;
