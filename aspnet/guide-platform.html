DETAILED REFERENCE GUIDE

ASP.NET Core DI, logging, cloud and search

Concept, purpose, code examples and production considerations with hospital application scenarios.

Dependency injection

DI supplies dependencies instead of constructing them inside business classes. Register services in the composition root and depend on abstractions where that creates a useful boundary.

builder.Services.AddScoped<IPatientService, PatientService>();
builder.Services.AddScoped<IPatientRepository, SqlPatientRepository>();
,

Transient, scoped and singleton lifetimes

Transient creates a new instance each resolution; scoped is typically one per HTTP request; singleton lives for the application lifetime. Never capture scoped DbContext in a singleton.

builder.Services.AddTransient<IFormatter, Formatter>();
builder.Services.AddScoped<IPatientService, PatientService>();
builder.Services.AddSingleton<ISystemClock, SystemClock>();
,

Scrutor and DI containers

Scrutor adds assembly scanning and decoration to Microsoft DI. Autofac is an alternative DI container with advanced registration/lifetime features. Start with built-in DI unless a concrete need justifies more.

builder.Services.Scan(scan => scan
 .FromApplicationDependencies()
 .AddClasses(c => c.AssignableTo<IValidator>())
 .AsImplementedInterfaces()
 .WithScopedLifetime());
,

Avoid captive dependencies

A singleton must not capture a scoped service. Use IServiceScopeFactory for background/singleton work that needs request-scoped dependencies.

public sealed class ImportWorker(IServiceScopeFactory scopes)
{
 public async Task RunAsync(CancellationToken ct)
 {
  await using var scope = scopes.CreateAsyncScope();
  var db = scope.ServiceProvider.GetRequiredService<HospitalDbContext>();
  await db.Patients.CountAsync(ct);
 }
}
,

ILogger and structured logging

Use message templates with named properties so logs can be searched and aggregated. Add correlation context and avoid sensitive patient data or credentials.

logger.LogInformation("Appointment {AppointmentId} booked for patient {PatientId}", appointmentId, patientId);
,

Serilog and NLog

Serilog and NLog provide structured logging pipelines with sinks/targets for console, files and centralized observability. Configure retention, redaction and environment-specific outputs.

builder.Host.UseSerilog((context, config) => config
 .ReadFrom.Configuration(context.Configuration)
 .Enrich.FromLogContext());
,

Cloud hosting and services

Deploy to Azure, AWS or Google Cloud using managed app/container services, databases, secrets and monitoring. Design for health probes, graceful shutdown, scale and backup.

var connection = builder.Configuration.GetConnectionString("HospitalDb")
 ?? throw new InvalidOperationException("Database connection is missing.");
,

Elasticsearch, Solr and Sphinx

Search engines index content for full-text and faceted search. They should normally be derived search projections, not the authoritative system of record for billing or appointments.

public interface IPatientSearch
{
 Task<IReadOnlyList<PatientSearchHit>> SearchAsync(string query, CancellationToken ct);
}
,

Secrets and configuration

Use user-secrets locally and managed secret stores in production. Rotate credentials, scope permissions and keep secrets out of appsettings files and Git history.

dotnet user-secrets init
dotnet user-secrets set "ConnectionStrings:HospitalDb" "<development-secret>"
