How the backend fits together

HTTP Client / Browser
        ↓
ASP.NET Core (Kestrel, Middleware, Routing)
        ↓
Endpoints / Controllers / Razor Components
        ↓
Application Services + Validation + Authorization
        ↓
Domain Rules
        ↓
Infrastructure (EF Core / Dapper / Cache / Messaging)
        ↓
SQL Server / Redis / External APIs / Message Broker

Start with a modular application and add distributed infrastructure only when requirements justify it. Authentication and authorization must protect every sensitive operation, particularly patient and billing records.
