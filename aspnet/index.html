ASP.NET Core

A separate, practical reference for building secure, maintainable HTTP services and web applications with ASP.NET Core. C# language concepts are covered in the C# section; this track focuses on the web framework and its application ecosystem.

Running project: Hospital API — patients, doctors, appointments, admissions, invoices, payments and ward occupancy. Examples use modern ASP.NET Core / .NET 10 style unless a version note says otherwise.

How this track relates to C# and .NET

  • C# language: syntax, types, OOP, generics, LINQ, exceptions, delegates and async/await.
  • .NET platform: runtime, SDK, CLR, garbage collection, assemblies, hosting primitives and base libraries.
  • ASP.NET Core: HTTP requests, endpoints, middleware, web security, API design, web hosting and application integrations.

Start with the C# fundamentals and the .NET platform, then use this track to build an API. Database, GitHub and CI/CD material remains in the shared engineering references.
