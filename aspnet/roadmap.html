FRAMEWORK LEARNING MAP

ASP.NET Core roadmap

This sequence is based on the uploaded one-page ASP.NET Core roadmap (page 1). The source map groups framework basics, data, dependency injection, communication, background work, testing, microservices, CI/CD and architecture. The list below turns those clusters into a structured reference sequence.

Source note: The uploaded roadmap is an ecosystem map, not a strict sequence. It names multiple alternatives in several areas; this reference explains the core concepts first and treats tools as options rather than mandatory dependencies.

1. Prerequisites and web fundamentals

  1. C# language foundations and .NET CLI / SDK
  2. Git and GitHub collaboration
  3. HTTP/HTTPS, methods, status codes, headers, cookies and JSON
  4. SQL fundamentals, relational design, constraints and stored procedures
  5. General development skills, data structures and algorithms

2. ASP.NET Core foundations

  1. ASP.NET Core application structure and hosting
  2. Kestrel, host, WebApplication and environment
  3. Request/response lifecycle and routing
  4. Minimal APIs and endpoint mapping
  5. MVC controllers and REST APIs
  6. Razor Pages and Razor Components overview
  7. Middleware pipeline, filters and attributes
  8. App settings, configuration providers and options

3. Data access and persistence

  1. Database fundamentals, relational vs NoSQL choices
  2. Entity Framework Core: DbContext, entities and change tracker
  3. Code First, migrations and schema evolution
  4. Relationships and constraints
  5. Lazy, eager and explicit loading
  6. Stored procedures and raw SQL when appropriate
  7. Dapper and RepoDB as lightweight alternatives
  8. SQL Server, PostgreSQL, MySQL/MariaDB and NoSQL overview

4. Dependency injection, caching and observability

  1. Built-in dependency injection and service registration
  2. Transient, scoped and singleton lifetimes
  3. DI containers and composition-root principles
  4. Memory cache and distributed cache
  5. Redis and cache invalidation strategies
  6. Structured logging, ILogger, Serilog and NLog
  7. Search and cloud service integration overview

5. API communication and integration

  1. REST API conventions, versioning and pagination
  2. Object mapping: manual mapping, AutoMapper and Mapperly
  3. GraphQL with Hot Chocolate and OData overview
  4. gRPC and typed API clients
  5. WebSockets and SignalR Core
  6. API gateway concepts, Ocelot and YARP

6. Background processing and messaging

  1. Hosted services and BackgroundService
  2. Task scheduling: Hangfire, Quartz.NET and Coravel
  3. Message brokers: RabbitMQ, Kafka, Azure Service Bus and alternatives
  4. Message bus abstractions, MassTransit and NServiceBus overview
  5. Retries, idempotency, outbox pattern and distributed consistency

7. Testing, quality and delivery

  1. Unit testing with xUnit, NUnit or MSTest
  2. Assertions and test data: Shouldly, AutoFixture and Bogus
  3. Mocking with Moq, NSubstitute or FakeItEasy
  4. Integration tests with WebApplicationFactory
  5. End-to-end tests with Playwright or other browser tooling
  6. Testcontainers, Respawn and .NET Aspire testing
  7. GitHub Actions, Azure Pipelines and other CI/CD systems
  8. Docker, container orchestration and deployment strategy

8. Architecture and additional ecosystem

  1. Layered architecture, Clean Architecture and modular monoliths
  2. Microservices trade-offs and service boundaries
  3. Client-side .NET: Blazor and .NET MAUI overview
  4. Template engines and document generation overview
  5. Resilience with Polly, validation with FluentValidation and mediation patterns
  6. Benchmarking, distributed locks and performance analysis
  7. Cloud, .NET Aspire, Dapr and Orleans overview

Use the detailed pages for implementation. Do not add every library to one application: choose a tool only when its problem and operational cost justify it.
