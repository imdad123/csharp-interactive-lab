ASP.NET Core host and Kestrel

The host owns application startup, DI, configuration, logging and graceful shutdown. Kestrel is the cross-platform HTTP server.

var builder = WebApplication.CreateBuilder(args);
builder.Services.AddControllers();
var app = builder.Build();
app.MapControllers();
app.Run();

.NET CLI, solution and project

The CLI creates, restores, builds, tests and publishes projects. A solution groups API, application, domain, infrastructure and test projects.

dotnet new sln -n Hospital
dotnet new webapi -n Hospital.Api
dotnet new classlib -n Hospital.Application
dotnet sln add Hospital.Api/Hospital.Api.csproj
dotnet add Hospital.Api reference Hospital.Application
dotnet restore
dotnet build

Data structures and algorithms

Backend request performance depends on appropriate data structures. Use dictionaries for keyed lookup, sets for uniqueness and queues for FIFO work.

var patientsById = patients.ToDictionary(p => p.Id); // expected O(1)
if (patientsById.TryGetValue(id, out var patient)) return patient;
,

SQL and database design

Design relational tables with primary keys, foreign keys, unique constraints, indexes and normalized relationships.

CREATE TABLE Patients (
 PatientId int IDENTITY PRIMARY KEY,
 MRN varchar(30) NOT NULL UNIQUE,
 FullName nvarchar(150) NOT NULL
);
CREATE TABLE Appointments (
 AppointmentId int IDENTITY PRIMARY KEY,
 PatientId int NOT NULL REFERENCES Patients(PatientId),
 StartsAt datetime2 NOT NULL
);
,

Stored procedures, constraints and triggers

Stored procedures encapsulate SQL operations; constraints protect integrity; triggers run implicitly after database events. Prefer explicit constraints for invariants and use triggers only when justified.

CREATE PROCEDURE dbo.GetPatient @PatientId int
AS
BEGIN
 SET NOCOUNT ON;
 SELECT PatientId, MRN, FullName FROM dbo.Patients WHERE PatientId=@PatientId;
END;
GO
ALTER TABLE Patients ADD CONSTRAINT UQ_Patients_MRN UNIQUE(MRN);
