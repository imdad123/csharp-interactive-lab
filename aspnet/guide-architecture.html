MediatR

MediatR implements in-process request/handler and notification patterns. It can organize use cases and pipeline behaviors, but direct service calls are often simpler for small applications.

public sealed record GetPatientQuery(int Id) : IRequest<PatientDto?>;
public sealed class GetPatientHandler(IPatientRepository repo)
 : IRequestHandler<GetPatientQuery, PatientDto?>
{
 public Task<PatientDto?> Handle(GetPatientQuery q, CancellationToken ct)
  => repo.FindAsync(q.Id, ct);
}
,

FluentValidation

FluentValidation expresses request validation in dedicated validators. Domain invariants must still be enforced in application/domain logic.

public sealed class RegisterPatientValidator : AbstractValidator<RegisterPatientRequest>
{
 public RegisterPatientValidator()
 {
  RuleFor(x => x.FullName).NotEmpty().MaximumLength(150);
  RuleFor(x => x.Mrn).NotEmpty().MaximumLength(30);
 }
}

Polly resilience

Polly provides retry, timeout, circuit breaker and other resilience strategies. Use bounded policies for transient remote failures and ensure retried operations are idempotent.

builder.Services.AddHttpClient<LabClient>()
 .AddStandardResilienceHandler();
,

Marten

Marten provides document database and event-store capabilities on PostgreSQL. Consider it when document/event-sourcing patterns fit the domain and the team can operate PostgreSQL.

var patient = await session.LoadAsync<PatientDocument>(patientId, ct);
patient!.FullName = request.FullName;
session.Store(patient);
await session.SaveChangesAsync(ct);
,

Scalar and OpenAPI

OpenAPI describes HTTP API contracts. Scalar provides an API reference UI for exploring the OpenAPI document; keep generated docs aligned with runtime endpoints.

builder.Services.AddOpenApi();
app.MapOpenApi();
// Configure Scalar UI package to read /openapi/v1.json

.NET Aspire

Aspire provides tooling/orchestration for distributed .NET applications, local composition, service discovery and observability integrations.

var db = builder.AddPostgres("postgres").AddDatabase("hospital");
var api = builder.AddProject<Projects.Hospital_Api>("hospital-api");
api.WithReference(db);

Dapr, Orleans and Steeltoe

Dapr provides distributed app building blocks such as service invocation, pub/sub and state. Orleans provides a virtual actor model. Steeltoe integrates cloud-native patterns for supported environments. These are specialized options, not mandatory ASP.NET components.

// Dapr service invocation concept:
var patient = await daprClient.InvokeMethodAsync<PatientDto>(
 HttpMethod.Get, "patient-service", $"api/patients/{id}", ct);
,

Distributed locks

Distributed locks coordinate work across application instances but require lease and failure handling. Prefer database uniqueness, optimistic concurrency and idempotency when those solve the problem.

await using var lease = await lockProvider.AcquireAsync("daily-billing", ct);
await billing.RunAsync(ct);

BenchmarkDotNet

BenchmarkDotNet runs repeatable microbenchmarks and measures time/allocations. Use production profiling for whole-system bottlenecks.

[MemoryDiagnoser]
public class MrnBenchmarks
{
 [Benchmark] public string Normalize() => " mr-1205 ".Trim().ToUpperInvariant();
}

Razor, Scriban and Fluid templates

Razor is native ASP.NET templating for views/components. Scriban and Fluid are standalone template engines for email/document generation. Restrict template access and avoid executing untrusted template code.

var template = Template.Parse("Hello {{ patient.name }}");
var output = template.Render(new { patient = new { name = "Amina" } });
,

Blazor and .NET MAUI

Blazor builds interactive web UIs with C# components. .NET MAUI builds cross-platform native clients. Both can consume ASP.NET Core APIs but do not replace backend responsibilities.

<button @onclick="Increment">Bookings: @count</button>
