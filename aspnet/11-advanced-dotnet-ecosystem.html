GUIDE 11 · ASP.NET CORE / .NET 10

Advanced .NET ecosystem and specialist skills

Choose advanced technologies based on real product requirements. Each topic includes its purpose, the knowledge to acquire, a practical example and an implementation exercise.

Learning rule: Do not just read the code. Create the project, run it, test normal and failure cases, inspect logs and SQL, then explain the trade-offs in your own words. Examples are focused teaching snippets; add the required namespaces, packages and surrounding application types when integrating them.

TOPIC 01

SignalR and real-time updates

Why this matters

SignalR provides server-to-client communication for live dashboards and notifications. It is not a replacement for durable business events or database state.

What you must learn

Learn hubs, groups, authorization, reconnect behavior, scale-out, backplanes and user-specific delivery.

Practical code example

[Authorize]
public sealed class WardHub : Hub
{
    public Task JoinWard(int wardId) => Groups.AddToGroupAsync(
        Context.ConnectionId, $"ward:{wardId}");
}

Build / practise

Build a ward occupancy dashboard that updates when beds change. Authorize group membership on the server.

TOPIC 02

gRPC and service-to-service communication

Why this matters

gRPC offers strongly typed contracts and efficient HTTP/2 communication. It is useful for internal service calls when both sides support the protocol.

What you must learn

Learn Protocol Buffers, `.proto`, generated clients, deadlines, cancellation, streaming and compatibility.

Practical code example

// Example .proto contract
syntax = "proto3";
service DoctorDirectory {
  rpc GetDoctor (DoctorRequest) returns (DoctorReply);
}
message DoctorRequest { string id = 1; }
message DoctorReply { string id = 1; string name = 2; }

Build / practise

Create a small internal doctor-directory service and compare gRPC with REST for usability and operational fit.

TOPIC 03

GraphQL and OData

Why this matters

GraphQL lets clients request shaped data through a schema; OData adds query conventions to REST-like endpoints. Both need strict authorization and query limits.

What you must learn

Learn schema design, resolvers, batching/DataLoader, N+1 prevention, query complexity, OData filters and field-level security.

Practical code example

// Resolver concept: authorize before returning protected patient data.
public Task<Doctor?> GetDoctor(Guid id, [Service] IDoctorService service,
    CancellationToken ct) => service.GetAsync(id, ct);

Build / practise

Prototype a doctor directory query. Prevent clients from requesting unbounded nested data or bypassing resource permissions.

TOPIC 04

Blazor and Razor Components

Why this matters

Blazor supports interactive web UI with .NET. It can be useful when a team wants C# across frontend and backend, but UI architecture and accessibility still matter.

What you must learn

Learn component lifecycle, parameters, cascading values, forms, validation, render modes, state management and server versus WebAssembly trade-offs.

Practical code example

@page "/doctors"
@inject IDoctorService Doctors
<h3>Doctors</h3>
@if (items is null) { <p>Loading...</p> }
else { @foreach (var doctor in items) { <p>@doctor.Name</p> } }
@code {
    private IReadOnlyList<DoctorDto>? items;
    protected override async Task OnInitializedAsync() => items = await Doctors.GetAllAsync();
}

Build / practise

Build a protected doctor directory UI and ensure server-side authorization is enforced independently of UI visibility.

TOPIC 05

SignalR, messaging and notification architecture

Why this matters

A live connection is transient; durable notification delivery needs persisted state and retry behavior. Separate event creation from real-time presentation.

What you must learn

Learn notification preferences, delivery status, outbox events, SignalR fan-out, push/email/SMS adapters and retry/dead-letter handling.

Practical code example

await notificationStore.SaveAsync(notification, ct);
await hubContext.Clients.User(userId)
    .SendAsync("NotificationAvailable", notification.Id, ct);

Build / practise

Persist notification records before sending live hints. On reconnect, let clients fetch missed notifications from the API.

TOPIC 06

Azure and cloud-native .NET

Why this matters

Cloud platforms provide managed hosting, databases, secrets, queues, monitoring and identity. Learn the concepts before specializing in one provider.

What you must learn

Learn App Service or container apps, Azure SQL, managed identity, Key Vault, Service Bus, storage, networking, autoscaling and cost controls.

Practical code example

builder.Services.AddAzureClients(clientBuilder =>
{
    clientBuilder.AddBlobServiceClient(configuration["Storage:Blob"]);
});

Build / practise

Deploy a non-production API using managed identity and a managed database. Document networking, secrets, backups and estimated cost.

TOPIC 07

.NET Aspire and local distributed development

Why this matters

Aspire helps orchestrate and observe multi-project distributed applications during development. It is a development workflow tool, not a substitute for production architecture.

What you must learn

Learn AppHost, service references, resource dependencies, health, dashboard, configuration and deployment integration.

Practical code example

var builder = DistributedApplication.CreateBuilder(args);
var cache = builder.AddRedis("cache");
var api = builder.AddProject<Projects.Hospital_Api>("hospital-api")
    .WithReference(cache);
builder.Build().Run();

Build / practise

Use Aspire to run the API and Redis locally with one command. Keep production deployment decisions explicit.
