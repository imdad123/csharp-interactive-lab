# Three-Month Study Plan

A focused plan for consistent progress. Adjust weekly pacing to available time; understanding and project completion matter more than rushing.

## Month 1 — C# foundations and professional language

### Week 1
- Program structure, types, variables, operators.
- Conditions, switch, loops.
- Methods, parameters, return values.
- Console input, parsing, and validation.
- Practice: patient registration console workflow.

### Week 2
- Arrays and collections.
- Classes, objects, fields, properties, constructors.
- Encapsulation, access modifiers, static members.
- Practice: Patient, Doctor, Appointment models.

### Week 3
- Inheritance, polymorphism, interfaces, composition.
- Exceptions and robust error handling.
- Generics and nullable reference types.
- Practice: appointment rules and service classes.

### Week 4
- Delegates, lambdas, events.
- LINQ and collection querying.
- Async/await and cancellation.
- Records, tuples, pattern matching, resource disposal.
- Practice: searchable appointment list and async service abstractions.

## Month 2 — SQL Server, T-SQL, and data access

### Week 5
- Relational design, keys, constraints, data types.
- SELECT, WHERE, ORDER BY, CASE, NULL.
- Joins and aggregation.
- Practice: hospital reporting queries.

### Week 6
- Subqueries, CTEs, window functions.
- INSERT, UPDATE, DELETE, OUTPUT.
- Stored procedures, views, functions.
- Practice: appointment and invoice procedures.

### Week 7
- Transactions, isolation, locking, blocking, deadlocks.
- Indexes, execution plans, statistics.
- Query Store and performance diagnostics.
- Practice: safe bed allocation and payment posting.

### Week 8
- ADO.NET, SqlConnection, SqlCommand, SqlDataReader.
- Parameters, DataTable, DataRow.
- EF Core, DbContext, migrations, relationships.
- Practice: connect HospitalApp to SQL Server.

## Month 3 — Testing, ASP.NET Core, and enterprise workflow

### Week 9
- Unit testing and test design.
- DTOs and testable business methods.
- Stubs, fakes, mocks.
- Practice: test patient and appointment rules.

### Week 10
- ASP.NET Core host and request lifecycle.
- Kestrel, middleware, routing, Minimal APIs.
- Request/response DTOs and validation.
- Practice: expose patient and appointment endpoints.

### Week 11
- Dependency injection and service lifetimes.
- EF Core query behavior and performance.
- Authentication, authorization, logging, exception handling.
- Integration tests.
- Practice: secure API and test database integration.

### Week 12
- Refine HospitalApp architecture.
- SQL performance and concurrency review.
- API documentation, configuration, deployment.
- Backup/restore and operational checklist.
- Final review: explain design decisions and trade-offs.

## Weekly routine
1. Learn the purpose and mental model.
2. Read and run a concise example.
3. Rebuild the example without copying.
4. Apply it to HospitalApp.
5. Write tests for important behavior.
6. Review mistakes and summarize the concept in your own words.
