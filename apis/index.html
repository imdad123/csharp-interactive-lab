API Engineering

A separate reference for designing, documenting, securing, testing and operating professional APIs with ASP.NET Core. This is distinct from the general ASP.NET Core framework menu because API design deserves its own engineering discipline.

Running API project: build versioned APIs for patients, doctors, appointments, admissions, invoices, pharmacy, reports and external hospital integrations. Apply the same contract, validation, security and testing standards to every module.

What this menu covers

  • HTTP and REST resource design, methods, status codes and headers.
  • DTOs, model binding, validation, errors, OpenAPI and versioning.
  • Authentication, authorization, OAuth/OIDC, JWT, CORS and rate limiting.
  • Idempotency, concurrency, caching, file transfer, webhooks and long-running jobs.
  • Integration tests, contract tests, load tests, observability and API governance.

How it connects to ASP.NET Core

The ASP.NET Core track teaches the framework and application infrastructure: hosting, middleware, dependency injection, EF Core, background services, deployment and architecture. This API track applies those capabilities to the design of reliable HTTP contracts. Study both; they complement each other.
