Platforms and where they fit

  • SQL Server + T-SQL: common in Microsoft/.NET enterprise environments, hospitals, finance, reporting and organizations using Windows/Azure ecosystems.
  • MySQL: widely used in PHP applications, WordPress, SaaS products, web hosting and many cloud deployments.
  • PostgreSQL: important production-grade open-source platform, especially in modern web, cloud-native and data-intensive systems.
  • SQLite: embedded/local database for applications, testing, mobile and lightweight workloads—not a replacement for every server database.

SQL is a language standard, but each engine has its own data types, functions, procedural language, indexing features, concurrency behavior and administration tools. We will teach portable SQL first and explicitly label dialect-specific syntax.

Tools to practice

  • SQL Server Management Studio (SSMS), Azure Data Studio where applicable, sqlcmd and SQL Server Profiler/Query Store.
  • MySQL Workbench, mysql client, EXPLAIN and Performance Schema.
  • pgAdmin and psql for PostgreSQL comparisons.
  • Database migrations and versioning through EF Core, Flyway or Liquibase concepts.
