DATABASE CURRICULUM

Professional SQL roadmap

The goal is not merely to write SELECT statements. Learn to design, secure, tune, back up and operate relational databases in production.

Phase 1 — Relational foundations

  1. Relational model, tables, rows, columns and relationships.
  2. Primary keys, foreign keys, unique/check/default constraints.
  3. Normalization (1NF–3NF), practical denormalization and data integrity.
  4. Data types, NULL semantics, collations, precision and date/time handling.
  5. SELECT, aliases, filtering, sorting, DISTINCT and pagination.

Phase 2 — Querying and reporting

  1. INNER, LEFT, RIGHT and FULL joins; self joins and cross joins.
  2. Aggregates, GROUP BY, HAVING and conditional aggregation.
  3. Subqueries, correlated subqueries, EXISTS and set operators.
  4. CTEs, recursive CTEs and derived tables.
  5. Window functions: ROW_NUMBER, RANK, LAG, LEAD and running totals.
  6. Reporting queries, date dimensions, summaries and export-friendly result sets.

Phase 3 — SQL Server and T-SQL

  1. SSMS, databases, schemas, users, roles and server/database configuration.
  2. T-SQL variables, batches, control flow and error handling with TRY/CATCH.
  3. Stored procedures, input/output parameters and execution plans.
  4. Views, inline/table-valued functions and when not to use scalar UDFs.
  5. Temporary tables, table variables, dynamic SQL and parameterization.
  6. IDENTITY, sequences, OUTPUT clause, MERGE caveats and safe upsert patterns.
  7. Transactions, isolation levels, locking, blocking and deadlocks.
  8. Indexes, included columns, filtered indexes, statistics and Query Store.
  9. SQL Agent jobs, backup/restore, point-in-time recovery and disaster recovery.
  10. Security: least privilege, schemas, encryption, auditing and secrets.

Phase 4 — MySQL in production

  1. MySQL server architecture, InnoDB, storage engines and configuration basics.
  2. MySQL data types, AUTO_INCREMENT, generated columns and constraints.
  3. MySQL SQL dialect, functions, date operations and JSON support.
  4. Indexes, EXPLAIN, query plans, slow query log and Performance Schema.
  5. Transactions, isolation levels, row locks, deadlocks and InnoDB behavior.
  6. Users, grants, backup/restore, replication concepts and high availability.
  7. Stored procedures, triggers and events—use deliberately, not by default.

Phase 5 — Cross-database engineering

Compare T-SQL and MySQL syntax for identity generation, pagination, date functions, string functions, upserts, JSON, stored procedures, error handling, transactions and indexing. Learn ANSI SQL portability and how to isolate vendor-specific queries.

Phase 6 — Production operations and capstone

  1. Connection pooling, application transactions and safe retry design.
  2. Schema migrations, backward-compatible database changes and deployment ordering.
  3. Monitoring, slow-query analysis, capacity planning and index maintenance.
  4. Backup verification, restore drills, RPO/RTO and disaster recovery.
  5. Build HMS reporting: daily appointments, occupancy, revenue, outstanding balances and pharmacy stock.
