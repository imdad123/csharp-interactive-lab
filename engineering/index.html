TRACK 07

DevOps, CI/CD & Cloud Engineering

Learn the path from a developer's commit to a safe production release, and how to operate the application after deployment.

Capstone: automatically test, build, package, deploy and monitor the Hospital HMS API and frontend across development, staging and production.

Core roadmap

  1. Linux/Windows server fundamentals, shell, processes, services, permissions and networking.
  2. Git branching, pull requests, code review, tags, semantic versioning and release notes.
  3. Build systems, dependency management, artifacts and reproducible builds.
  4. CI concepts: triggers, jobs, runners/agents, caching, artifacts and environment variables.
  5. Automated quality gates: unit tests, integration tests, lint, SAST, dependency and secret scanning.
  6. CD concepts: environments, approvals, deployment strategies, rollback and database migrations.
  7. Docker: images, containers, volumes, networks, registries and multi-stage builds.
  8. Container orchestration: Kubernetes concepts, pods, deployments, services, ingress, config and secrets.
  9. Infrastructure as Code: Terraform and cloud-native templates; immutable infrastructure concepts.
  10. Cloud networking: VPC/VNet, subnets, DNS, load balancers, firewalls, private endpoints and TLS.
  11. Identity and secrets: IAM/RBAC, managed identities, secret managers, key vaults and rotation.
  12. Observability: structured logs, metrics, traces, dashboards, alerts and OpenTelemetry concepts.
  13. Reliability: health checks, autoscaling, backups, restore drills, high availability and disaster recovery.
  14. Cost, governance, tagging, least privilege and production incident response.
