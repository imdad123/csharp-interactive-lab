How to use this: learn the concept in C# first, then compare the idiomatic alternative in PHP, JavaScript/TypeScript and Python. Do not assume a feature with a similar name behaves exactly the same.

Important differences to understand

  • C# and TypeScript have compile-time type systems; PHP and Python also support type declarations/hints, but runtime enforcement and static analysis differ.
  • JavaScript is dynamically typed; TypeScript checks types before runtime and does not add runtime validation automatically.
  • PHP's request lifecycle is commonly request/response per web request; long-running workers and async models require attention to the runtime/framework.
  • Python protocols and duck typing encourage behavior-based contracts; C# interfaces provide explicit nominal contracts.
  • LINQ is a unified query API in .NET; other languages combine built-in collection methods, comprehensions, iterators and libraries.
