PHP collections, iteration and asynchronous work

Choose data structures, transform records and handle long-running work using PHP's idioms.

Arrays and collection choices

PHP arrays are ordered maps. They can behave like indexed lists, dictionaries or mixed structures. Use clear key conventions and validate data at boundaries.

$patients = [
    ['id' => 101, 'name' => 'Amina', 'active' => true],
    ['id' => 102, 'name' => 'Bilal', 'active' => false],
];

$byId = [];
foreach ($patients as $patient) {
    $byId[$patient['id']] = $patient;
}
$patient = $byId[101] ?? null;

Filtering, mapping and reducing

$activePatients = array_filter(
    $patients,
    fn(array $p): bool => $p['active']
);

$names = array_map(
    fn(array $p): string => $p['name'],
    $activePatients
);

$total = array_reduce(
    [1000, 1500, 750],
    fn(int $sum, int $fee): int => $sum + $fee,
    0
);

For larger application domains, Collections from Laravel or a dedicated collection library can improve expressiveness. Understand whether operations return arrays, iterators or lazy collections.

Generators and iteration

function readAppointments(PDO $pdo): Generator
{
    $stmt = $pdo->query(
        'SELECT AppointmentId, PatientId, AppointmentDate
         FROM Appointments ORDER BY AppointmentDate'
    );

    while ($row = $stmt->fetch(PDO::FETCH_ASSOC)) {
        yield $row;
    }
}

foreach (readAppointments($pdo) as $appointment) {
    // Process one row at a time instead of loading all rows.
}

Generators are useful for large exports and streaming transformations. They do not automatically make a database query asynchronous.

Callbacks, closures and first-class callables

$isValidPatient = static function (array $patient): bool {
    return ($patient['active'] ?? false) === true;
};

$valid = array_filter($patients, $isValidPatient);

Closures can capture variables with use. Prefer explicit inputs and small callbacks so hidden dependencies do not make code difficult to test.

Asynchronous work in PHP

Traditional PHP-FPM request handling is synchronous from the application's perspective. Async and concurrent execution is typically provided by a runtime or library such as ReactPHP, Amp, Swoole or RoadRunner. Queues and background workers are often a more straightforward production choice for reminders, reports and long-running tasks.
