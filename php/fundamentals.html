PHP · MODULE 01

PHP fundamentals

Understand what PHP does in a web request and learn the language features that power hospital workflows.

Why PHP exists in a web application

A browser cannot directly execute PHP source code. The web server runs PHP on the server, PHP can validate input and access data, and the server returns HTML or JSON to the client. Never send secrets or database credentials to the browser.

Types and strictness

PHP is dynamically typed, but modern PHP supports scalar type declarations, return types and strict_types. Use explicit types in application code to make contracts easier to reason about.

<?php
declare(strict_types=1);

function calculateConsultationTotal(float $fee, float $discount): float
{
    if ($fee < 0 || $discount < 0 || $discount > $fee) {
        throw new InvalidArgumentException('Invalid fee or discount');
    }
    return $fee - $discount;
}

echo calculateConsultationTotal(1800.00, 100.00);

For real financial accounting, prefer integer minor units or a decimal-safe money strategy rather than assuming binary floating-point is exact.

Arrays and associative records

$patient = [
    'id' => 1205,
    'mrn' => 'MR-2026-001205',
    'name' => 'Amina Khan',
    'active' => true,
];

$appointments = [];
$appointments[] = ['patient_id' => 1205, 'status' => 'Booked'];

Associative arrays are convenient for request data and simple structures. As the application grows, use DTOs/value objects and domain classes to avoid unstructured arrays spreading through every layer.

Forms and validation

$name = trim($_POST['name'] ?? '');
$ageInput = $_POST['age'] ?? null;
$age = filter_var($ageInput, FILTER_VALIDATE_INT);

$errors = [];
if ($name === '') $errors['name'] = 'Patient name is required';
if ($age === false || $age < 0 || $age > 125) {
    $errors['age'] = 'Enter a valid age';
}

Input from forms, query strings, headers and APIs is untrusted. Validate according to business meaning. Escape output for the context where it is rendered; validation alone does not prevent XSS.

Functions and separation of concerns

Keep pure business calculations separate from superglobals, HTML and SQL. A function should receive the values it needs and return a result. This makes it reusable in web requests, CLI commands and tests.

Practice task

  1. Create a patient registration form.
  2. Validate name, age, phone and date of birth on the server.
  3. Generate an MRN through a dedicated service—not from a user-editable field.
  4. Show field-level errors and preserve safe form values.
  5. Write tests for the validation and fee-calculation functions.
