Database engineering with PDO

A hospital application stores important facts: patients, doctors, appointments, invoices and payments. Database access must be secure, consistent and predictable.

Connect with PDO

$pdo = new PDO($dsn, $username, $password, [
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES => false,
]);

Keep credentials outside source control. Configure connection timeouts and TLS appropriately for your database server.

Prepared statements prevent SQL injection

$statement = $pdo->prepare(
    'SELECT PatientId, PatientName FROM Patients WHERE PatientId = :id'
);
$statement->execute(['id' => $patientId]);
$patient = $statement->fetch();

Never build SQL by concatenating patient-provided values. Placeholders bind values, not table or column names; dynamic identifiers must come from a strict allow-list.

Transactions protect billing consistency

try {
    $pdo->beginTransaction();
    $header = $pdo->prepare(
        'INSERT INTO Invoices (PatientId, TotalAmount) VALUES (:patient, :total)'
    );
    $header->execute(['patient' => $patientId, 'total' => $total]);
    $invoiceId = (int) $pdo->lastInsertId();

    $line = $pdo->prepare(
        'INSERT INTO InvoiceLines (InvoiceId, Description, Amount) VALUES (:id, :description, :amount)'
    );
    $line->execute(['id' => $invoiceId, 'description' => 'Consultation', 'amount' => $fee]);
    $pdo->commit();
} catch (Throwable $exception) {
    if ($pdo->inTransaction()) $pdo->rollBack();
    throw $exception;
}

Use transactions when invoice header, lines and accounting entries form one business operation. Validate totals and handle concurrency deliberately.

Repositories and query design

A repository can encapsulate patient persistence, but do not create abstractions that merely rename every PDO call. Keep query intent clear, select only required columns, paginate large result sets and index real search predicates. Avoid N+1 query patterns when listing appointments with related doctors.
