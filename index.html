How the language tracks connect

We do not teach each language in isolation. First learn a concept in a primary language, then compare the equivalent idea and its trade-offs in PHP, JavaScript/TypeScript and Python. The concept may be similar while the type system, runtime, standard library and ecosystem differ.

Production engineering is part of the curriculum

  1. Build correctly.Language fundamentals, architecture, data modeling, validation and business rules.
  2. Prove it works.Unit, integration, API, database and end-to-end tests; static analysis and code review.
  3. Deliver safely.Git workflows, CI/CD pipelines, artifacts, migrations, approvals, rollback and release strategies.
  4. Run reliably.Cloud compute, managed databases, storage, networking, secrets, logs, metrics, backups and disaster recovery.
