One consistent teaching standard

  1. Understand the reason.Learn which real problem led to the feature or tool.
  2. Understand the mechanism.Build a correct mental model before memorizing commands or syntax.
  3. Apply it to a hospital workflow.Use patients, doctors, appointments, billing, pharmacy, wards and reports as examples.
  4. Work like a professional.Cover security, maintainability, testing, performance, collaboration and deployment.
