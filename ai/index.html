TRACK 08

AI Engineering

A production-oriented path from machine learning foundations to LLM applications, retrieval systems and reliable AI services.

HMS examples: clinical document search, hospital policy assistant, appointment assistant and carefully governed decision-support prototypes. Clinical use requires expert validation, privacy controls and regulatory review.

Roadmap modules

  1. Python, statistics, linear algebra and data handling foundations.
  2. Machine learning concepts, supervised/unsupervised learning and model evaluation.
  3. Neural networks and deep learning fundamentals.
  4. Transformers, tokenization, embeddings and LLM behavior.
  5. Prompt design, structured outputs, tool calling and function schemas.
  6. Vector databases, chunking, retrieval, reranking and RAG evaluation.
  7. Agent workflows, orchestration, tools, state and human approval boundaries.
  8. Fine-tuning concepts, adapters/LoRA and model selection.
  9. Evaluation datasets, hallucination testing, safety, privacy and red teaming.
  10. FastAPI model services, queues, caching, observability and cost controls.
  11. Model serving, GPU/cloud infrastructure, deployment and monitoring.
  12. Healthcare data governance, de-identification, access control and clinical validation.
