PART 1 · C# MASTERCLASS

C# Masterclass roadmap

A 68-topic C# language reference followed by .NET runtime fundamentals. ASP.NET Core web development is documented in its own separate track.

Target stack: C# 14 / .NET 10 concepts, Visual Studio, HospitalApp.Console first, then ASP.NET Core, SQL Server and production deployment. Version-specific features are labelled in the relevant reference pages.

Phase 1 — C# Foundations

  1. Variables and data types
  2. Console input/output, TryParse and input validation
  3. Operators, conditions, if/else and switch
  4. Loops: for, foreach, while and do-while
  5. Arrays and multidimensional arrays
  6. List and collection operations
  7. IEnumerable, ICollection, IList and IReadOnlyList
  8. Dictionary, HashSet, Queue and Stack

Phase 2 — Object-Oriented Programming (OOP)

  1. Classes and objects
  2. Constructors and encapsulation
  3. Methods, parameters and return values
  4. Method overloading
  5. Access modifiers: public, private, protected and internal
  6. Properties and backing fields
  7. Value types vs reference types
  8. Inheritance
  9. Composition and association
  10. Polymorphism
  11. Abstract classes and methods
  12. Interfaces and abstraction

Phase 3 — Generics and Data Processing

  1. Generics and generic methods
  2. Generic classes and constraints
  3. Generic repositories
  4. LINQ fundamentals
  5. Where, Select and FirstOrDefault
  6. Any, All, Count and aggregates
  7. OrderBy, ThenBy and sorting
  8. GroupBy and data grouping
  9. Deferred execution
  10. IEnumerable vs IQueryable
  11. LINQ method syntax vs query syntax

Phase 4 — Professional C# and Application Architecture

This phase covers robust error handling, configuration, observability, validation, testing and maintainable application architecture.

  1. Exception handling
  2. Exception propagation and custom exceptions
  3. File handling
  4. JSON serialization and deserialization
  5. Configuration and appsettings.json
  6. Environment variables
  7. Logging with ILogger
  8. Data Annotations and validation
  9. Unit testing with xUnit
  10. Debugging in Visual Studio
  11. SOLID principles
  12. Clean Architecture in .NET
  13. Separation of concerns and project structure
  14. Dependency Injection in depth
  15. DTOs, entities and request/response models
  16. Repository and service patterns
  17. Business logic and application workflows

Phase 5 — Modern C#

  1. Nullable reference types
  2. Pattern matching
  3. Switch expressions
  4. Expression-bodied members
  5. Object initializers
  6. Collection initializers
  7. Target-typed new
  8. Init-only properties
  9. Required properties
  10. Records and record types
  11. Structs and enums in practical applications
  12. Extension methods
  13. Tuples and deconstruction
  14. Advanced LINQ and performance

Phase 6 — Delegates, Events and Asynchronous Programming

  1. Delegates
  2. Action, Func and Predicate
  3. Lambda expressions
  4. Events and event handling
  5. Delegates vs events
  6. Async and await

After topic 68, extend into Task and ValueTask, cancellation tokens, exception flow in async code, parallelism vs concurrency, channels and safe concurrent access. ASP.NET Core, HTTP APIs, middleware, EF Core web integration, caching, authentication and deployment are covered separately in the ASP.NET Core track.

Phase 7 — .NET platform and runtime

  1. .NET SDK, CLI, solution/project files, NuGet and build configuration
  2. CLR, IL, JIT, garbage collection, assemblies and runtime diagnostics
  3. ADO.NET fundamentals: connections, commands, readers, DataTable and DataRow
  4. Runtime diagnostics, profiling, garbage collection and memory performance

Phase 8 — HospitalApp production capstone

  1. Domain model: patients, doctors, appointments, admissions, invoices and payments.
  2. Console solution: Domain, Application, Infrastructure and tests.
  3. Validation, DTO mapping, use cases and business rules.
  4. SQL Server persistence, migrations, transactions and audit history.
  5. Console application workflows, service boundaries and robust exception handling.
  6. Automated tests, CI pipeline, environment configuration and monitoring.
