C# & T-SQL MASTERY REFERENCE

The complete mastery roadmap

The exact learning sequence: console-first C#, professional .NET engineering, SQL Server and T-SQL, then an end-to-end HospitalApp project.

Study approach: Understand the problem first, then the concept, syntax, trade-offs, and its use in a real enterprise application.

How this course is taught

Each concept is studied through its original problem, why it was introduced, why simpler approaches are insufficient, its mental model, concise syntax, a HospitalApp example, and professional practices. Keep lessons concise and practical rather than expanding every subject into unnecessary theory.

Part 1 — C# language mastery

  1. Fundamentals: program structure, data types, variables, operators, conditions, loops, methods, arrays.
  2. Collections and LINQ: List, Dictionary, IEnumerable, filtering, projection, sorting, grouping, aggregation.
  3. OOP: classes, objects, constructors, encapsulation, inheritance, polymorphism, interfaces, composition.
  4. Generics, interfaces, DTOs, SOLID, dependency inversion, service boundaries and architecture.
  5. Exceptions, validation, files, serialization, persistence concepts and resource disposal.
  6. Modern C#: records, tuples, pattern matching, nullable reference types, extension methods, attributes, reflection, memory and performance concepts.
  7. Delegates, Action, Func, lambdas, events, async/await, Task, cancellation, concurrency.

Part 2 — .NET platform and engineering

  1. .NET internals: Roslyn, CLR, CTS, CLS, assemblies, IL, JIT, Native AOT, garbage collection and hosting.
  2. Testing: unit tests, DTO-based testability, stubs, fakes, mocks, integration tests and API tests.
  3. ASP.NET Core: Kestrel, host, dependency injection, middleware, routing, Minimal APIs, validation, security and logging.
  4. Data access: ADO.NET, SqlConnection, SqlCommand, SqlDataReader, DataTable, DataRow, EF Core, DbContext, migrations and transactions.

Part 3 — SQL Server and T-SQL

  1. Relational design, schemas, keys, constraints, data types and core SELECT queries.
  2. Joins, aggregation, subqueries, CTEs, window functions and reporting queries.
  3. INSERT/UPDATE/DELETE, stored procedures, views, functions, temp tables, dynamic SQL, transactions and error handling.
  4. Indexes, execution plans, statistics, Query Store, locking, blocking, deadlocks, backups, restore, SQL Agent and security.

Part 4 — HospitalApp.Console

Start with a console application before SQL or web development. Progress from registration and menus to collections/LINQ, domain classes, interfaces, DTOs, persistence, async/events, tests, SQL Server, APIs and production readiness. The console project teaches the core language and domain without hiding it behind a framework.

Definition of mastery

  • Explain why a concept exists and when to use it.
  • Write maintainable C# and SQL with clear responsibilities.
  • Design relational schemas and safe transactional workflows.
  • Test business rules independently from forms and APIs.
  • Build, secure, diagnose, optimize and deploy enterprise applications.
